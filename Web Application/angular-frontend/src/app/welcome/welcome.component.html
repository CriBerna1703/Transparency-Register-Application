Transparency Register Explorer

Explore meetings between interest representatives and European Commission officials through interactive visualizations.

What is this application?

This tool allows you to explore data from the EU Transparency Register, focusing on meetings between lobbyists and European Commission officials.

The application combines network graphs, timelines and statistics to help you understand who meets whom, when, and how often.

Image placeholder

How does it work?

  • Use filters to select a time range and meeting criteria
  • Explore relationships through an interactive graph
  • Analyze trends over time using the temporal view
  • Inspect detailed information by selecting nodes
Image placeholder

Main views

  • Overview: aggregated statistics and summaries
  • Graph view: relationships between actors
  • Temporal view: meetings distributed over time
  • Histogram: frequency analysis by entity
